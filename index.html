flowmn

AI agent + web app + CLI

01

Overview

flowmn turns particle image velocimetry (PIV) recordings into velocity fields and analyses them. It is built to be driven by an AI agent, such as Claude Code or Codex, through its MCP server or its command line. The agent does the technical work; anything that is your call, a trade-off or a number only you know, comes to you as a question, and everything it does goes into an activity log you can watch live in the web app.

The correlation engine is written from the published literature, with a fast mode after RapidPIV, and runs on a multi-core CPU, on NVIDIA GPUs, or on Apple Silicon and AMD GPUs through PyTorch. It reads image pairs and LaVision DaVis projects, planar or stereo. It works straight after install, with no internet connection, and runs without an agent too, from the terminal or the web app.

02

How it works

The clips follow one session on flowmn’s demo data, a synthetic cylinder wake. The agent’s chat on the left is scripted; the web app on the right, the operations the agent calls and every number shown are real.

Ask in plain words

Point the agent at your images and say what you want to learn. It measures the seeding density, the particle-image size and the range of displacements, chooses the interrogation windows from them, and writes the change and its reason to the activity log, which the web app shows as it happens.

You make the calls

The agent drafts an analysis plan (here from the bluff-body wake template) and turns everything it can’t measure into a question for you: the sample rate, the cylinder diameter, the free-stream speed, and whether to favour accuracy or speed. You answer and approve in the web app, the terminal or the chat. The plan’s steps run only once you’ve approved them.

Check one pair, then process them all

One pair is previewed before the whole recording runs. Fast mode follows the RapidPIV approach: a dense optical-flow estimate stands in for the coarse passes, then one correlation pass corrects it. Processing runs in the background on the CPU’s cores or a GPU, with its progress in the web app.

Analyse with premade tools

The approved steps run tools from the built-in suite: turbulence statistics, vorticity and vortex detection, POD and DMD, spectra, phase averaging, boundary layers and wakes, profiles and probes. Each result comes back as numbers and figures, which the agent reads and explains, with units.

Or build your own

When no premade tool fits, the agent writes one into the project’s tools folder, checks it, runs it and tells you where it is, so you can read the method. You can write tools yourself too, starting from a template.

03

Results

A project is a plain folder you can read without flowmn: the settings, the plan with every question, answer and approval, the activity log, the vector fields in one HDF5 file with the settings that made them, and each analysis run’s numbers, arrays, figures and tables. On a 4-core CPU a 2048 × 2048 pair takes about 1.4 s, or 1.2 s in Fast mode.

flacmn

Desktop app + phone app

01

Overview

flacmn is a desktop app for people who maintain a digital music library. It looks at every album, verifies the file format and quality, lets you adjust the tags and album art, and sends the music to your phone in whatever format you want.

02

How it works

Search your library

One box searches artist, album, song, genre and label across the whole library. Every album is marked Lossless, Hi-res or Lossy from its files, so the ones worth a closer look stand out.

Check the real quality

Each track’s spectrum is measured. A FLAC made from an MP3 or AAC shows the encoder’s cutoff and is flagged as a lossy source: here every track of Blue Lines stops near 16 kHz.

Fix tags and covers

Tags are checked against MusicBrainz, and missing covers come from the Cover Art Archive, only when you ask.

Pair your phone

The phone app finds the computer on the same Wi-Fi. Type the six-digit code shown on the computer and the two are paired.

Choose a format and send

Choose albums and a format: the original, FLAC, ALAC, AAC or MP3, with every size shown before anything is sent. flacmn converts them if needed and sends them to the phone.

Play it on the phone

New albums show first under Recently added. The phone app plays each song with its own quality shown, and a swipe brings up an XY scope in the cover’s colour.

03

Results

Every album gets a clear verdict, Hi-res, Lossless or Lossy, with the spectrogram that backs it up, tags checked against MusicBrainz and a cover in place.

In the quality check above, all nine tracks of a FLAC copy of Blue Lines stop near 16 kHz, a lossy encoder’s cutoff: the files say FLAC, but the sound came from an MP3 or AAC. Kind of Blue passes as lossless and goes to the phone as ALAC.
